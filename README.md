# ComfyUI Minimize Shortcut

- **Author:** HTMLDigger
- **Date:** 2026-11-13
- **Description:** A small ComfyUI frontend extension for minimizing and expanding nodes. Use `Ctrl+Shift+M` to toggle selected nodes, or use the node right-click menu.
- **More details:** [GitHub repository](https://github.com/Ripax/ComfyUI-HTMutilitty)

## Installation

1. Open your ComfyUI `custom_nodes` directory.
2. Clone or download this repository into a folder named `ComfyUI-HTMutilitty`.
3. Restart ComfyUI and refresh the browser page.

No additional dependencies are required.
